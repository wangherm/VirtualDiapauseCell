# 核心任务与 biotime 主线

版本 0.2，2026-10-02。根据用户要求及 thesis 方法章节重新组织项目：**Diapause 状态与维护、Exit biotime、gene/TF waves、programme/regulon waves 是核心；14 个功能领域服务于这些动态任务。** 这次调整设计和定义，没有导入内部结果、成员表、轴权重或训练标签。

## 顶层任务

| ID | 核心问题 | 第一阶段的目标输出 |
| --- | --- | --- |
| DC01 状态、维护与深度 | 当前是什么状态？有何维护历史？在规定刺激下是否容易恢复？ | 状态证据、维护参考偏离、实测历史；功能深度有对应响应数据才输出 |
| DC02 Exit clock / biotime | 样本在明确恢复分支上走到哪里？ | 有版本和锚点的坐标、适用范围与不确定性，保留细胞类型差异 |
| DC03 Gene / TF expression waves | 哪些基因在相对进程的哪个位置怎样变化？ | 实际曲线、幅度、方向、形状、支持范围、单位间稳定性；TF 转变位置单列 |
| DC04 Programme / pathway / regulon waves | 程序如何展开、持续或不同步？ | 来自样本表达的程序分数和曲线、同位置偏离、成员/权重/覆盖以及证据类型 |

这四项是共同描述状态的任务，不是串联的四个独立 Qwen，也不是每个输出都已具有监督。DC02 是组织坐标，DC03/DC04 与它并列为主要学习和评价目标；不能为提升 clock 相关性牺牲 programme 信息。DC01 的功能深度科学优先级高，但计算必须等待功能读数。

## Biotime 的对象与来源

核对 thesis §2.7.7、§2.7.15、§5.6.1–5.6.6 后，保留以下对象，禁止统一成一个无来源的 `clock_score`：

| 对象 | 构造与解释 | 比较边界 |
| --- | --- | --- |
| whole-embryo biotime | 整体胚胎表达的锚点方向和投影 | embryo 尺度；不是实际释放小时 |
| biotime_bulk | 把 bulk 方向转移到单细胞基因空间，并用单细胞锚点重新校准 | 名称带 bulk，但输出是单细胞坐标 |
| biotime_sc | 在单细胞中构建、平衡细胞类型的参考方向 | 与 bulk-derived template 特征仍可能有依赖；构造分开不等于统计独立 |
| cell-type-specific biotime | 每个细胞类型以自己的条件参考建立坐标 | 类型内稳健性分析；单独校准后不自动拥有共同绝对标尺 |
| M4 exit clock | 冻结 Early-Diapause→Developing 方向的基线模型 | 独立记录轴版本、特征、锚点和拟合来源，不自动与其他轴认作同一对象 |

参考校准的 0 和 1 表示所选锚点，不是百分比恢复。超出锚点的投影保留；轴不随新样本重拟合。记录 `coordinate_id`、`axis_version`、`level`、`branch`、`feature_set_id`、`normalisation`、`anchor_ids`、`fit_studies/units`、训练冻结哈希和覆盖范围。实际小时保留在独立字段。

上述是方法来源登记；本项目尚未取得可用于开发的轴文件，不能称“已复现 M4”。将来使用 M4 输出监督时标明蒸馏，不能把复现老师坐标当独立生物学验证。

## Waves 是核心数值对象

thesis §2.7.8、Chapter 5 和 §2.7.9、Chapter 6 支持保留表达波形及相对位置。波形是沿 biotime 的变化，不默认周期振荡、绝对激活时间或调控因果。

每条 wave 至少记录：对象 ID（gene/TF/programme/regulon）、坐标及分支、物种与细胞类型、观测点及单位、未标准化表达曲线、形状标准化曲线、幅度、形状类别、转变或峰谷位置及区间、支持的坐标范围、平滑/插值参数、缺失覆盖、bootstrap 稳定性和拟合来源。原始测量和曲线拟合值分别保存。

保留 EarlyUp / Up / LateUp、EarlyDown / Down / LateDown、Early/Mid/Late Peak 与 Valley，以及 Flat / Unclassified。已有模板是形状基线，不能强迫每条曲线入类。先用未做逐基因 z-score 的观测判断幅度和噪声，再做形状比较；不能凭标准化后的起伏判断原始变化是否显著。

拟合范围外默认不声称观测支持。thesis 的具体平滑、插值和 Flat 判据需对原始代码单独核验，当前没有照抄其参数或实现；观察曲线描述与未来预测采用不同访问范围。预测未来时不能用全时间序列平滑后的曲线作为输入。

TF RNA wave、共动态基因 wave、motif-supported regulon score 及计算 KO 位移是四种证据。半最大位置或 lag 只有在交点/方向可辨识时输出，并提供重采样不确定性；多峰、平坦或多个交点不能硬给唯一时间。表达先后不证明 TF 先激活或驱动下游。

## Programme 波形与功能解释

DC04 的曲线来自实际样本表达和明确成员/权重；enrichment 负责注释，`-log(P)` 不作表达幅度。一个 pathway 的成员可以分属上升、下降或不同峰位，先保存分支后再考虑汇总，避免相消。

K13 是经验状态程序；temporal templates 是表达形状；M01–M14 是功能目录，三者多对多。未导入内部 K13 成员，不按富集名称生成新成员。今后数值输出须同时提供基因权重与样本分数，以及定义/训练来源。

核心研究关系为：

`observed_programme = reference(biotime, cell_context, branch) + deviation + measurement_error`。

有重复或明确噪声模型才可能区分 deviation 和测量误差；否则报告合并残差与不确定性。不能把所有偏离去噪成参考曲线。非单调或平坦 programme 通常不能反推出唯一局部 clock，因此先报告数值偏离，在可辨识时才报告相对提前/滞后。

## Depth-conditioned Exit waves

科学问题保留为：相同 Exit biotime 的样本，在不同维护历史或起始功能深度下，wave 的幅度、形状、位置或程序间协调是否不同？

先研究 `reference(biotime, context)`；有释放前功能状态和释放后观测时，再研究 `reference(biotime, initial_depth, context)`。初始深度必须来自有操作定义的恢复响应或清楚标记的弱参考，不能设为 `1 - exit_clock`。维护时长、Early/Late 标签和功能深度分别保存。

Early/Late 端点不能自动构成连续维护轨迹。Early 来源的释放分支也不能补出 Late→Exit 时序。技术噪声、真实幅度差异、不同路径与进程滞后应作为竞争解释，不一律归因为更深休眠。

## 第一轮验收与执行顺序

1. 冻结坐标对象、样本单位及论文/数据访问边界，选可用的公开恢复数据；不把已有数据 accession 当作已下载。
2. 先建立公开数据上的状态/clock 数值基线，并注册 cell-cycle ablation 与匹配随机移除对照；所有特征和归一化只在训练单位拟合。
3. 同时建立 gene/TF 与 programme wave 对象，保留幅度和范围；按生物单位、研究留出评价，clock 输入基因与被评价 wave 的成员分开或交叉拟合。未分开的只能称描述性耦合。
4. 主要终点一起报告：clock 定位、wave 数值/幅度与形状稳定性、programme 偏离、细胞类型异步及真实处理差异的保留。参考残差为零不作为单独优化目标。
5. 再用 LLM 连接证据和波形、比较不同解释；原始数值结果不得由文字替代。有真实恢复/存活读数时增加 depth 与结局评价；之后才进入状态转移训练。
