# Virtual Diapause Cell：合作讨论说明

> 定义快照说明：本文保留项目设计与数据边界。v0.4.0 的代码、真实执行和能力状态以 `docs/MODULAR_INTEGRATION_CN.md`、`docs/STATUS.md` 及 `reports/v0.4.0/` 为准。
版本 0.2，2026-10-02。本文是新项目的研究定义，不是实验结果报告。

## 项目主线与优先级

本版将 thesis 的动态组织方式提升到顶层：DC01 状态/维护/深度、DC02 Exit biotime、DC03 gene/TF waves、DC04 programme/pathway/regulon waves。14 个功能领域作为这些任务的解释词典。具体坐标、波形对象、thesis 方法衔接和验收见[核心优先级](CORE_PRIORITIES_CN.md)。

最有辨识度的问题是：相同 biotime 的样本是否以相同方式恢复，哪些程序发生了不同步；有起始维护/功能深度数据时，再研究这种差异是否随起始状态改变。细胞类型异步、Entry–Exit 逆转/持续变化及组成/类型内效应进入第一轮评价设计。

## 研究问题

给定一个样本的表达与实验背景，我们希望回答：它处于哪一种休眠相关状态、在明确的进入或恢复过程上走到哪里、各功能程序实际呈现什么、哪些偏离可信，以及在有对应训练数据时下一阶段可能怎样变化。

“低增殖”不足以定义 diapause。可恢复的发育暂停、普通细胞静息、衰老相关停滞、急性应激、正常发育与细胞死亡必须区分。跨物种首先共享功能概念和有来源的证据关系，不能假定相同基因名、相同 pathway 名或相同 clock 值意味着相同状态。

## 为什么重新开始

FactorBridge 问的是“LLM 能否帮助从 noisy expression 中选择可恢复的因子”。两轮真实训练完成后，第二轮语义模型在 56 个验证候选上全部 uncertain，得到零列 W；数值重估基线在当前弱参考下仍有非空输出。新增 programme 候选全部被旧 PCA 参考标 uncertain、研究分布偏斜、token loss 与下游选择质量不一致，是需要验证的失败解释。见[已归档实验](https://github.com/wangherm/FactorBridge/blob/archive-2026-10-01-pilot/experiments/README.md)。

新项目不继续优化旧 support-selection 任务。我们先固定要解释的生物学问题、可观测状态与评价终点，再选择算法。FactorBridge 的审计、缺失覆盖、分组和真实运行记录原则值得保留；旧 adapter 和标签不作为初始化知识或真值。

## 三个层次，不是三套重复框架

**知识层**保存“系统—状态—处理—时间—测量—结果—出处—限制”的实验记录。数据库提供词汇和注释，原始论文提供有背景的机制证据。综述用于检索扩展，不能和其引用的实验算作独立支持。阴性结果、未测量与相反方向的结果都保留。

**状态层**把表达等观测映射为过程分支、clock 和 programme 向量。初始比较包含数值模型、固定知识辅助模型、通用 Qwen 检索版和领域适配版；相同数据划分与知识访问范围下检验 LLM 是否有增益。RNA 分数称“相关表达”，不会被命名成自噬通量、代谢流量或耐受能力。

**转移层**是后续世界模型的可检验含义：学习 `p(next_state | current_state, intervention, delta_t, context, history)`。论文知识可限制假设空间，预测幅度与不确定性仍需真实测量。只有观察时间序列时称条件预测；真实干预留出成功后，才讨论对应范围内的干预响应能力。

Virtual Yeast 提供按功能组织系统的架构启发，其 Perspective 不是本项目模块已验证的依据。[原文](https://www.nature.com/articles/s41586-026-10574-9)

## 模块与模型的关系

本次提出 14 个可修订功能领域，覆盖信号感知、复制、基因组维护、染色质、RNA、蛋白稳态、回收、能源、储备、应激、膜稳态、身份结构、细胞间协调及存活控制。它们可重叠，也允许未知，不是互相独立的因果部件。

每个模块记录功能问题、子过程、可测通道、不能推断的量、适用背景、文献与 GO 检索锚点。一个 programme 可以连接多个模块；一个模块也可以包含方向相反的 programme。当前没有真实 gene membership 表，不能从模块名称伪造成员。

模块不等于模型数量。早期适合一个共享的小型数值编码器、多个带缺失掩码的输出，外加一个使用证据的语言模型。Qwen/Qwen3-4B-Instruct-2507 可继续作为语言基线；是否领域持续预训练、LoRA 或只做检索，由独立的证据提取与问答验证决定。知识不必全部写入参数，检索便于更新和追溯。

## Diapause clock 的明确含义

第一版优先定义有明确释放事件的 reactivation 坐标；是否存在足够公共数据，仍需准入审计。进入、维持、终止、终止后仍受环境限制的静息，以及恢复应分别保留，不能无证据拼成单条时间轴。

实际经过时间、分子进程、休眠历史和恢复能力是不同字段。昼夜节律是某些物种的上游机制，不是本项目预测的进程 clock。同一位置的样本仍可有不同的程序组合；残差不能被强行校正掉。

拟议状态关系为 `programme = reference(clock, context) + deviation`。参考只在训练研究拟合。clock 评价不仅看时间排序，还检查留出功能终点；programme 评价要用与 clock 输入分离的成员或独立模态，避免自证循环。表达位置不等于细胞命运。

## 什么算第一轮成功

首先，在完全留出的研究或实验单位上，模型应比时间标签、增殖分数、线性／样条数值基线更好地恢复预先定义的状态或独立 programme，并保持真实处理差异。在有结果测量的子集，另行检查释放后恢复比例、恢复延迟或生存终点；缺少这些标签则不宣称预测了恢复能力。

其次，知识模型必须能给出可查来源、正确实验背景、相反证据和未知。先用审核后的实验记录做抽取、条件辨别与证据比较 SFT；Qwen 自动生成的摘要不能直接成为 gold。选择 checkpoint 用任务指标，不能只看语言 loss。

最后，转移模型须在未来时间、未见处理或独立研究上对照 mean、last-state、线性趋势及相同表征的数值模型。不能把不同时间采集的单细胞配成真实同一细胞轨迹。

## 下一步的具体产物

1. 先登记 biotime 坐标、锚点与单位，明确 gene/TF 及 programme wave 的数值输出和共同评价终点；功能领域按这些任务补充证据。
2. 对公开胚胎 diapause 数据核对真实文件、单位、时点、处理和功能 readout；确定一个确实可训练的数值任务。
3. 按 paper family / study / biological unit 冻结数据与知识划分，记录预训练模型可能已有的文献污染。
4. 先运行数值和检索基线，再决定小规模 Qwen 适配；重新完成真实服务器环境及前后向保存重载检查。

当前完成定义与工具，不称作已经建立了虚拟细胞或训练了世界模型。所有内部 killifish 及其结果派生标签默认仍在冻结边界内；以后若使用其中一部分开发，必须另立协议，不能继续把它称为最终未见测试。
