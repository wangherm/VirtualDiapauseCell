# v0.4.0 模块化整合与首个公共试点

这是独立的 VirtualDiapauseCell 项目。FactorBridge 仅提供方法经验，没有导入旧 adapter、弱标签或训练分布。正式 Python 路径只有 `src/vdc/`；桌面起步包的解压副本仅留在被 Git 忽略的 `work/` 中。

## 三层定义

- 科学任务仍是 **DC01 状态与维护、DC02 biotime、DC03 gene/TF waves、DC04 programme/regulon waves**。
- 生物功能解释仍采用现有 **M01–M14**。没有把起步包中的 DM01–DM06 另立为第二套定义。
- 下表是工程边界，不是新的生物学模块。Clock 与 programme 是共同目标；一个可运行的重构模型不能替代 clock 的科学验证。

| 工程边界 | 输入与输出 | 当前实施范围 |
| --- | --- | --- |
| 数据观测 | 表达、基因成员、mask、coverage → programme 观测 | 显式尺度；WormBase 稳定 ID；缺失不当作测量零 |
| 知识 | 经审核且有来源的文本 → 检索结果、可选 Qwen 向量/SFT | 独立入口；真实 Qwen 执行仍为 not_run |
| 共享状态 | programme 观测 → latent、重构、可选 clock | 小型 Transformer；只在有合格 clock 标签时训练和输出 clock |
| waves | 命名坐标、训练参考样本 → 低阶曲线与残差 | gene/TF/programme/regulon 类型分开；范围外默认不输出 |
| 扰动端点 | 匹配背景下的对照状态、动作 → 处理终点或明确的差异目标 | Ridge 基线；源样本/对照链接不得跨 split |
| 释放后转移 | 初始状态、动作、实际间隔 → 下一状态 | 单步基线；不伪造单细胞配对，不做多步 rollout |
| 功能读出 | 状态与条件 → 有协议和实测标签的连续终点 | 无功能标签则 unavailable，不能用 1-clock 代替 depth |
| 评价与研究发布 | checkpoint、真实评价、显式研究审阅 → 限定能力的本地调用 | 本轮未批准研究模型，未启动服务 |

## 扰动策略如何放进框架

候选目录位于 `knowledge/perturbation_candidates.json`，保留 22 条候选资源/实验臂，**不是 22 项独立研究，也不是全部已验证或已下载**。起步包提供的描述标为 supplied candidate，不能自动成为训练事实。

1. **遗传/药物端点响应**：KO、单/双突变、救援与处理—对照比较。持续存在的基因型属于背景；只有实际新施加的动作进入急性干预字段。
2. **历史条件下的恢复**：休眠多久、释放/复喂、间隔多久。以群体或独立生物单位组织，不把相同编号直接认定为纵向同一个体。
3. **功能结果**：存活、再进入能力、再生或其他实测终点。筛选中的竞争适应度、增殖与存活不能互换；统一 depth 尚未成立。

GSE185815 与 PRJNA503701 保留旧目录 VAL/L4-OOD 边界；内部 killifish、K13、M4、内部结果文本不进入训练或知识检索。本轮的真实扰动训练尚未执行。

## 首个真实数据接入

选择 [GSE288723](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE288723)。官方 SOFT 和表达文件实际读取成功，文件 URL、字节数、SHA256 固定在 `configs/public_pilot_sources.json`。

- 下载文件含 **54 个样本、19,909 个 WormBase 基因**；Salmon 估计计数含小数，按 `estimated_counts` 处理，不强制取整。
- 首轮纳入 **36 个无 UV 的 dauer/exit 样本**：4 种休眠历史 × 3 个释放后时点 × 3 个生物重复。每份 RNA 来源是约 8,000 条虫的 pool，不是 8,000 个独立样本。
- 15 个 UV 样本与 3 个 L3 样本已下载，但未进入本轮重构训练。后续对照关系与动作契约单独审核。
- 在所有历史和时间条件中，将重复编号 1/2/3 分别整体放入 train/validation/test，各 12 个 pool。这是保守的重复编号分块，**不是已证实的纵向配对**。GEO 未完整给出跨条件的亲本培养物/批次谱系，不能宣称研究间泛化或已排除所有批次相关性。
- 使用 [GO/WormBase 正式注释](https://geneontology.org/docs/download-go-annotations/downloads/) 的内容哈希快照，采用 26 个既有 GO 锚点的直接正向成员；排除 NOT、ND、非 6239 物种和本研究 PMID 注释。得到 **24 个可用 programme**。免疫系统和细胞周期两个锚点在该直接成员策略下不可用，不用全零替代。
- 这是直接注释子集，没有向 GO 后代传播；成员覆盖不完整、programme 存在重叠。分数是样本内基因秩的均值，**不是通路活性实测值**。GO 数据按 CC BY 4.0 使用并保留来源。

本轮没有合格的分子 clock 标签。实际小时数只作为时间元数据，clock 监督 mask 全为 false；模型文件、预测文件和报告不输出随机 clock。真实数据运行的是 **programme → 状态重构 → 独立保留样本评价**。另按四种历史分别拟合 **实际小时坐标的一阶曲线与残差**，明确命名 `elapsed_hours_since_dauer_exit_NOT_biotime`。这不等于完成 biotime waves。

## 已修复的集成问题

修复未训练 clock 被保存为验证数值的问题；增加 Salmon 小数计数的显式尺度；为响应数据加内容校验；评价时核对训练样本 ID、生物单位和共享链接，防止换名后重新当作 test。新旧编码器、programme 顺序和预处理版本必须匹配；调用者必须把响应的 `representation_id` 绑定到实际编码器/预处理的指纹，不能只写“32维”。

起步包 SHA256 为 `3ef9358227406926611e3aa4136d94c91240dcbcafb803c8a1be5005fd5454f7`，其内部清单 52 个文件校验一致。原包的测试记录仅作历史参考。本地重新执行的记录见 `reports/v0.4.0/`；未导入原包中的私人参考目录或历史测试结果到公共仓库。

## 下一条科学依赖链

需要先审核一个明确的公共分子坐标定义及其训练参考、方向和适用背景，再训练 clock、按该坐标拟合 waves，并用未参与建轴的观测或功能终点检验。不能因为 programme 的人工遮盖重构误差下降，就认定 biotime、机制或扰动预测成立。

共享编码器更新后，依赖它的 response/readout 必须重新检查。Qwen 先在实际 GPU 上完成独立加载、前后向和保存重载验证，再做审核知识语料训练与消融。研究批准与软件测试是不同状态；本轮不申请或生成科学批准。
