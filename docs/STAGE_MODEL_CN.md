# CW-stage-1：供合作者讨论的阶段模型

本版解决一个有限问题：给定授权开发背景中的相对表达和可靠身份，在训练参考上定位样本，描述 gene/TF RNA/programme 沿参考的变化，并保留观测偏离。模型可以给出冻结隐藏基因面板的表达预测。它不是一个能从任意物种、平台直接推断深度和未来命运的世界模型。

## 一个定义与代码路径，按视图固定读出

输入是严格校验的整数 counts、固定基因顺序、固定 programme 成员及来源身份。数值输入同时保留基因相对排序和本地相对 log 丰度；后者不是绝对每细胞 RNA 量。clock、成员、scaler、wave 参数来自既定开发训练单位；生物学单位、pool 与派生 profile 不能混为独立重复。

Clock 作为共同坐标用于组织变化，但不把它当唯一信息通道。默认 bulk 读出额外接收**当前实际可见**的 programme residual；core 和粗身份保持较简单的 clock＋身份读出。所有视图继续并列直接 Ridge 和 identity mean，以区分解释性与预测精度。不同视图不必共享一组读出参数。

可将数值链理解为四步：

1. 用固定成员与尺度计算可见 rank/幅度和覆盖 mask。
2. 在对应身份的训练参考中求 unclipped clock，分别判定参考范围与可辨识性。
3. 用固定 wave 得到参考表达；记录实际观测相对参考的偏离。
4. 用该视图预先固定的读出预测隐藏表达，同时输出同支持集合上的强基线。

残差支路读取的是可见测量，不是 clean reference 或隐藏目标。训练 residual 来自训练内参考，非按 pool cross-fit。改变隐藏基因 counts 不得改变安全输入、rank、幅度或 clock；不过粗身份仍依赖既有源注释聚合，不能宣称完整细胞重注释流程已独立于目标表达。

## 身份模型负责什么

已有可靠身份优先继承。Base 与领域 adapter 的 Qwen 只作辅助证据测试，输出固定字段 `identity/e1/e2/e3/status`。每个证据字段只能是一条当前卡内观测编号或 null。原卡的数值接受门槛保持不变；无数值提示和人为撤证据分别评价。

引用合法，只证明该编号确实来自当前正表达观测，不证明 marker 的生物学特异性。原卡 top1 复述不算独立注释；源粗注释一致性不算 lineage gold。格式失败、证据错误、明确 unknown、数值冲突与接受分别报告。

本轮不新增 LoRA，不把修复接口称为新增知识训练。模型真实 base/adapter 版本与每次生成的 prompt、token、停止观察绑定保存。新协议必须重新生成，旧列表不会被截成三个编号来改写分数。

## 为什么按视图收拢

经核验的修订结果支持 bulk 保留 clock 以外的信息，但直接 Ridge 仍略优。Core 的范围内改善没有稳定转化为全请求改善；粗身份 residual 在验证 pool 上明显变差。这些结果支持不同视图使用不同强度的修正，不能推出因果机制。

因此本轮只增加一个事先固定的更强收缩诊断（alpha=100）。结果无论好坏都保留，不依据它继续网格搜索或自动替换默认路线。详细私有分数在 run 模型卡与统一表中，不公开到仓库。

## 冻结什么、如何使用

`stage_snapshot.json` 绑定实际代码/配置摘要、数值参数、基因与 programme 词典、尺度、身份参考、wave、读出、预测、Qwen 来源和评价。共享大模型权重不重复复制，用实际 fingerprint 定位；原始 counts 留在服务器授权缓存，不进入报告 ZIP。

浏览器直接复用现有服务，仅展示保存的开发预测和统一结果表。默认列表只有三视图主结果，辅助分支可显式查看。数值默认路线会实际调用并重载复核；这不等于已经开放新上传数据的推理服务。

统一表同时列出强基线、每种条件、范围内/外、所有请求覆盖与独立单位数。拒绝更多样本后得到更低 MSE 不视为改进。Late 维持结果不能解释成正常 Exit 成绩。

## 阶段完成与未解决问题

固定队列完成、默认调用与重载正确、真实知识评价及局限已记录、HTTP 浏览验证通过后，服务器保存阶段实验快照并打包。模型可以低于基线；科学能力不能因此自动升级。若 GPU 或数据依赖失败，保存可用部分，明确 `partial_not_closed`，不假装已经封完。

Early 范围外、blood 缺参考、单 pool 锚点无法充分校准不确定性均进入局限，不靠 clip 或事后扩范围修饰。TF RNA waves 不等于 TF 调控活性。跨物种语义映射、功能 depth、复杂未来响应及后期身份重审保留下一阶段，不再增加本轮任务。已查看的样本仍非独立 test。
